Privacy policy

Last updated: October 21, 2026

Sky Timelapse is a personal tool operated by its owner for their own YouTube channel. It is not offered to the public.

Data accessed

Through the YouTube Data API, the app uses the owner's authorization to upload videos, set thumbnails, add videos to playlists, and read basic channel details (name and subscriber count) on the owner's own channel. It does not read, collect, or store data about viewers or any other YouTube users.

Storage

The OAuth token is stored only on the owner's private home server and is never shared or sold. Videos contain only footage of the sky.

Deletion

The app keeps no YouTube API data. The stored OAuth token is deleted from the server immediately if access is revoked or on request; to request deletion, email the contact below. Uploaded videos can be deleted at any time in YouTube Studio.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions. See also Google's privacy policy. This app uses YouTube API Services and is subject to the YouTube Terms of Service.
